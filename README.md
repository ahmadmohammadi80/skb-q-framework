# skb-q-framework

## Current real-model evidence

[RoPE experiment, 16 November 2026](experiments/rope_20261116/README.md) contains pinned-model execution code, complete per-block results, matched packed Q/K storage, a published-angle-rule transplantation, checks, and explicit limitations.

This is research code. Independent novelty and submission readiness are not established. Historical archives and synthetic prototypes are retained for provenance; their results are not interchangeable with the new experiment.

## Stronger controls and independent architecture

[Follow-up evidence](experiments/rope_20261116/stage1/README.md) adds an exact alternating-optimization control, Pythia-70M at three byte-matched budgets, full per-block losses, uncertainty intervals and serialized patch checks. The stronger optimizer reproduces the proposed choices. These findings do not resolve independent novelty or submission readiness.
